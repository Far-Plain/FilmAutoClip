# FILM / FRAME

一个完全在浏览器本地运行的胶片扫描图分帧工具。它会自动判断正像黑边或原始负像片基，裁出完整画格，并保持原图片格式与原始像素尺寸导出。

## 使用

直接双击 `index.html`，或在本目录启动任意静态文件服务：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

1. 一次选择或拖入一张或多张 JPG、PNG、WEBP、BMP、TIF/TIFF 扫描图；之后可用“添加底片”继续追加。
2. 工具会依次识别所有底片，并默认自动判断正像或原始负像。通过顶部任务条切换底片，分别检查和校正裁切框、选择状态与旋转角度。
3. 负像自动采样不准确时，使用“吸管校正”在画格间隔或片条边缘点击 1–5 次；必要时再调整边界阈值、边界连续度和向内收边。
4. 点击导出后只选择一次目录。所有底片中已勾选的画格会保持各自源格式，直接逐张写入该目录，不进行打包。

## 处理说明

- 所有像素处理都在本地浏览器中完成，不会上传图片。
- 自动模式会同时评估正像黑边和负像片基。负像片基从低纹理颜色候选中选取，并以能形成连续、规则画格的结果作为最终判断；外部扫描背景不会直接作为片基。
- 每张底片可以保存独立的图像类型与手动片基采样点。吸管采样只作用于检测缩略图，不会反相或修改导出的原始像素。
- 多底片任务仅长期保留原始 `File` 引用和裁切参数；切换与导出时按需载入一张源图，批量导出也会逐张生成并立即写盘，以控制大尺寸 TIFF 的内存占用。
- 双轨扫描会先分别定位两条片轨，再在每条片轨内部独立分帧；单侧片轨缺失时会根据照片与扫描底色的边界恢复。
- 当两张照片通过中间黑轨连接、导致前景无法自然分开时，会参考已识别片轨的宽度估算缺轨范围，再在估算范围内寻找照片与白色扫描底的真实交界；中间黑轨会作为左右片轨的共享边界。
- 位于扫描图最上方或最下方的照片可以使用图像边缘作为裁切边界，不要求四周都有完整黑边。
- JPG、PNG、WEBP、BMP、TIF/TIFF 会按原格式和原扩展名输出；PNG/BMP 使用无损编码，JPG/WEBP 可选择输出质量。
- 输出质量默认为 100%；对 JPG/WebP 代表编码器最高质量，对 PNG/BMP/TIFF 则保持无损输出。BMP 输出为兼容性良好的 24-bit 无压缩格式。
- TIFF 只在预览阶段生成 8-bit 显示副本；导出不再经过 Canvas/RGBA8，而是直接裁切解压后的原始通道样本。常见的交错式 RGB/灰度 8-bit、16-bit TIFF 会保留原始位深、通道数、SampleFormat、ICC/XMP、分辨率等顶层元数据，旋转也直接作用于原始样本。
- 裁切后的 TIFF 重新写为无压缩格式，因此原文件的 LZW/ZIP 等压缩方式和文件大小可能改变，但 16-bit 像素值不会降为 8-bit。分平面、CFA/RAW、YCbCr 子采样或非 8/16-bit 打包布局会停止导出并提示原因，避免静默丢失信息。
- 多页 TIFF 目前处理第一页，界面会显示原文件页数。
- 输出尺寸是裁切框在原图上的实际像素尺寸；分析阶段的缩略图只用于加速黑边检测。
- 在支持文件夹访问的浏览器中，每次导出都会显示目录选择窗口；目录访问句柄会保存在浏览器本地，使下次窗口默认从上次目录打开。用户可以直接确认，也可以在窗口中切换到新目录；同名文件不会被覆盖，而会自动增加数字后缀。
- 文件夹批量保存建议通过 `http://localhost:8080` 打开，并使用最新版 Chrome 或 Edge。不支持目录选择的浏览器会回退为多个独立下载。
- 竖向画格默认旋转 90° 以横向预览，每张预览都可独立左右旋转；导出会应用各画格当前的预览角度，原图查看区的旋转则不会改变导出方向。
